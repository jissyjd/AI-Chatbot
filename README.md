# AI-Chatbot
This is a Chatbot for having simple conversations.

A simple AI chatbot built using Python and the Groq API.

**How It Works**

The program initializes the Groq client using the stored API key.

It prompts the user to enter a message.

The message is sent to the Llama 3.3 70B Versatile model.

The model generates a response.

The chatbot displays the response.

The process repeats until the user types exit.


Example:


AI Chatbot Started!

Type 'exit' to stop.


You: Hello

Bot: Hi! How can I help you today?



You: What is Artificial Intelligence?

Bot: Artificial Intelligence (AI) is a field of computer science that focuses on creating systems capable of performing tasks that typically require human intelligence.


You: exit

Bot: Goodbye!
